# Voxprint AI Movie Dubber

Voxprint AI Movie Dubber is a Windows desktop application that adds an AI-dubbed audio track to a movie. It separates the dialogue from music and effects, recognises and translates the speech, re-voices it with a cloned voice for each speaker and adds the result to the file as an extra audio track, leaving the video and the original audio untouched. Everything runs locally on your NVIDIA GPU.

**Status:** early development (pre-release). The application is installed with a small online installer that downloads its components during setup; the dubbing features are being completed step by step.
