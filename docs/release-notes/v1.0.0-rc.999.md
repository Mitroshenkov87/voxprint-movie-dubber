Release candidate of Voxprint AI Movie Dubber: **1.0.0 RC · build 999 "Hineni"** ("here I am", Genesis 22:1: ready to go out). This build is meant for the final install test before 1.0.0.

**Supported systems:** Windows 11 24H2 or newer, or a Linux distribution released in 2025 or later. An NVIDIA GPU is needed for useful speed.

Small online installer: Python, PyTorch and the other components are downloaded during setup.

**What's new since v0.1.0-pre.5**
- Version scheme: the release identity (1.0.0-rc, build 999, codename "Hineni") is kept in one place and shown in About, diagnostics, the installer and this release title.
- Less accent from the original actor: the default actor likeness is now 50% (was 70%), so more of the native library voice is mixed in. Each character card and the single-voice mode have an "Actor likeness" slider (0-100%); projects that saved 70% keep it.
- Clip-1 fixes: the voice reference is taken from one speaker only (padded, faded and re-checked by speech recognition); short lines are translated together with the next line of the same speaker, so an isolated "Yes!" is no longer mistranslated; "AI" stays "ИИ" in Russian and Title Case words are no longer turned into names; letter runs such as "Ewwwww." no longer become "www"; short interjections may move into the following pause instead of being sped up.
- Speed-ups: the spoken length is estimated before voicing, with at most one retry per line; speech recognition never silently falls back to the CPU when a CUDA GPU is present; voice/background separation is batched by free VRAM; models stay loaded between stages while they fit; the next stage is prepared while the GPU is busy; CUDA Graphs stay the default for dialogue.
- VRAM rule: the budget is free VRAM minus max(2 GB, 8% of the card), measured again before each voicing batch, with 1.2 GB counted per line in batched voicing.
- Thermal rule: GPU temperature, power and throttling are logged; cooling pauses are inserted only after 2.5 hours of work and only while the card stays hot or throttled.
- Code audit gate: every change and every installer build first runs ruff, mypy, bandit, pip-audit and a secret scan (gitleaks), plus weekly CodeQL; a serious finding stops the build. Findings from the first audit were fixed.
- A small easter egg on the splash screen.
