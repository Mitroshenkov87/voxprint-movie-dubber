Release candidate of Voxprint AI Movie Dubber: **1.0.0 RC · build 1001 "Bochan"** ("tested, proven", *even bochan*, Isaiah 28:16: the tested stone, the build that goes to its first test on real hardware).

**Requirements:** an NVIDIA GeForce RTX 40-series graphics card or newer and an NVIDIA driver from the 600 branch or newer, on Windows 11 24H2 or newer (64-bit) or on x86_64 Linux. Setup and the program stop with a clear message on older hardware.

**Downloads**
- **Windows full installer (offline, recommended):** download `VoxprintMovieDubber-Full-Setup.exe` and every `VoxprintMovieDubber-Full-Setup-N.bin` part into one folder, then start the `.exe`. It carries Python 3.14, PyTorch 2.11.0+cu130 and every other component, so setup needs no internet. The AI models (about 8 GB) are downloaded by the optional setup task or on first use.
- **Windows online installer:** the small `VoxprintMovieDubber-Setup.exe` downloads Python, PyTorch and the other components during setup.
- **Linux (preview):** `VoxprintMovieDubber-Linux-x86_64.tar.gz`. Unpack it and run `./install.sh`. It installs into `~/.local`, creates a Python 3.14 environment with uv, installs PyTorch 2.11.0+cu130 and adds the `voxprint-movie-dubber` command, a menu entry and the `.vxdub` file type. `./install.sh --uninstall` removes it.

Check every file against the SHA-256 table below (also in the `.sha256` files).

**What's new since build 1000 "Chazak"**
- One `BUILD.json` holds the build offset and the codename; the window, the splash, About, `--version` and the release title read it.
- Headless command line for other programs and scripts: `version`, `diagnose`, `fetch-models`, `run-project` and `info`, with `--json` output and documented exit codes. `--dry-run` discovers the machine and the job without loading or downloading models (exit 3 on a machine without a supported GPU).
- Suite icons for Save, Save As, Export and model download.
- Linux preview tarball with `install.sh`, checked in CI (install, `--dry-run --json`, uninstall).
- Public [roadmap](https://github.com/Mitroshenkov87/voxprint-movie-dubber/blob/main/ROADMAP.md) and a [documentation site](https://mitroshenkov87.github.io/voxprint-movie-dubber/) with a command-line reference generated from the program.
